How to get a Discord webhook URL

  1. Open your Discord server settings
  2. Go to Integrations → Webhooks
  3. Click New Webhook or select an existing one
  4. Copy the webhook URL and paste it above

Tips

  • Check interval: Lower values detect changes faster but make more API calls.
  • Log retention: Higher values keep more history but use more disk space.
  • Notification log: Controls how many recent sends show on the dashboard.
